# Heist Mod (Fabric 1.20.1)

Ограбления в стиле PAYDAY 2: банк и ювелирка, сейфы с кодами, ключ-карты трёх уровней, термобур, золото, деньги, украшения и картины.

## Как получить .jar

Нужен JDK 17 и Gradle 8.5+ (Fabric Loom 1.5).

    gradle build

Готовый файл: `build/libs/heistmod-1.0.0.jar` (файл с `-sources` не нужен).
Положи его в папку `mods` вместе с **Fabric Loader 0.15+** и **Fabric API 0.92.2+1.20.1**.

Без установки Java: залей папку в репозиторий на GitHub — workflow `.github/workflows/build.yml`
соберёт jar сам (вкладка Actions → Artifacts → heistmod-jar).

## Как играть

1. `/heist build bank` или `/heist build jewelry` — построит здание перед тобой (нужны права оператора).
2. Банк: сундук за стойкой (карта 1 + записка с кодом) → сейф персонала (карта 2) → кабинет менеджера
   (записка + сейф с картой 3) → красная карта открывает хранилище.
3. **Бур — это блок.** Поставь его вплотную к сейфу или двери хранилища, и он начнёт сверлить сам.
   Сейф — 20 сек, дверь хранилища — 60 сек и тревога. Бур может заклинить — ПКМ по буру, чтобы починить.
   Сломаешь бур — бурение остановится.
4. ПКМ по запертому сейфу открывает клавиатуру (4 цифры, мышью или с клавиатуры).
5. **Лут в сейфах случайный:** сейф, поставленный игроком, получает случайный код и 3–7 случайных стаков
   (деньги, золото, украшения, картины, блоки денег, кучи золота). Код видят операторы в строке над хотбаром.
6. **Камеры:** поставь камеры (смотрят туда же, куда ты) и компьютер охраны. ПКМ по компьютеру — список камер
   в радиусе 96 блоков. Выбери камеру и смотри её глазами (камера покачивается). `B` — следующая камера,
   `V` — выйти. Выход и при шаге в сторону или уроне. Клавиши меняются в настройках управления.
7. **Витрины:** «Витрина с украшениями» при разбитии даёт добычу, пустая — ничего.
8. **Картины** вешаются на боковую грань любого целого блока. Блоки денег и куч золота собираются из 9 пачек/слитков и обратно.

## Команды (права оператора)

- `/heist build bank|jewelry` — построить здание
- `/heist kit` — выдать бур, камеры, компьютер, картины и ключ-карты
- `/heist note` — записка с кодом сейфа, на который смотришь

В креативе все предметы лежат во вкладке «Ограбления». Сейфы, дверь хранилища и армированный сланец
в выживании не ломаются — убрать их можно только в креативе.
